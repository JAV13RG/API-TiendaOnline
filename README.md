# API de Tienda Online

Sistema centralizado para digitalizar la gestión de ventas, pedidos y mantener registros históricos consistentes.

## Requisitos Previos
- Python 3.x
- Git

## Instrucciones de Instalación y Ejecución

1. **Clonar el repositorio:**
    ```
    git clone [URL_DE_TU_REPOSITORIO]
    cd API-TIENDAONLINE

2. **Crear y activar ambiente virtual:**
    ```
    python -m venv .venv
    .venv\Scripts\activate

3. **Instalar dependencias:**
    ```
    pip install -r requirements.txt

4. **Ejecutar en el servidor local:**
    ```
    python manage.py runserver

El proyecto quedara disponible en *localhost://127.0.0.1:8000/*
